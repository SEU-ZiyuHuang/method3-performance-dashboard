# 方法三独立性能看板

直接用浏览器打开 `index.html`，或访问 https://seu-ziyuhuang.github.io/method3-performance-dashboard/ 。分享离线版时只需发送这一个 HTML 文件，其余文件不是查看依赖。

数据来自 `../runs/full` 的 399 个成功配置，以及 `../runs/repair_case100_k4` 的 1 个补跑配置，合并后 2—5 核共 400 个配置全部成功且通过独立复评。补跑使用 3.2.2 文件写入修复版，搜索规则、输入、官方评价器和 480 秒预算均与原 3.2.1 批次相同。原始失败记录保留不改。

页面提供四种核数的平均加速比、同组 100 样本口径、100×4 热力图、逐样本明细、搬运分析、搜索耗时、增核负收益清单，以及 HTML 与 CSV 导出。所有脚本、样式和数据内嵌，无 CDN、外部字体、数据请求或服务端接口。

在此目录执行 `python build_dashboard.py` 可根据已有结果重新生成。只使用 Python 标准库；不运行求解器、官方评估器，也不修改 `runs`。

`template.html` 是页面源码，`analysis.json` 是可复核的汇总，`build_check.log` 是生成检查记录，`publication.json` 记录发布位置。重新生成后公网版本不会自动同步。

`最终结果.csv` 和 `最终结果.json` 是合并后的完整 400 行成绩表，包含每行的批次来源和版本；看板已内嵌相同数据，查看时不依赖这些文件。
